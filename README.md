# ✈️ Авиа-калькулятор топлива – три версии для разных ролей

Данный проект представляет собой три варианта десктопного приложения для расчёта количества топлива для рейса самолёта. Разработано в рамках тестового задания.

Все версии используют единую логику расчёта, но отличаются интерфейсом и набором функций, что позволяет использовать их как конечным пользователям, так и тестировщикам.

---

## 📦 Общие возможности

- Расчёт топлива по формуле:  
  `Топливо = Скорость × Время × Коэффициент_типа × Коэффициент_погоды`
- Поддержка двух типов самолётов: **«большой»** и **«маленький»**.
- Три погодных условия: **нормальный**, **сильный ветер**, **дождь**.
- Валидация ввода – программа не падает при некорректных данных, выводит понятные сообщения об ошибках.
- Тёмная тема с синим акцентом (библиотека `customtkinter`).
- Встроенная информация о самолётах (картинка + описание) по нажатию на кнопку **ℹ️**.
- Копирование результатов через **Ctrl+C** (в любой раскладке, благодаря проверке по `keycode`) и через контекстное меню (правая кнопка мыши).

---

## 📂 Три версии приложения

### 1. Административная (для тестировщиков)
**Файл:** `fuel_calc_OVC_admin.py`

- ✅ Ручной ввод параметров.
- ✅ Прогон **18 встроенных тестов** с отображением статуса `PASS`/`FAIL` и сравнением ожидаемого и фактического результатов.
- ✅ Загрузка пользовательских тестов из **JSON-файла**.
- ✅ Отображение списка всех тестов в отдельном окне.
- ✅ Копирование результатов.

**Используйте эту версию, чтобы:**
- Проверить корректность алгоритма на наборе тестов.
- Добавить свои тесты через JSON.
- Выполнить регрессионное тестирование.

---

### 2. Пользовательская простая (для конечного пользователя)
**Файл:** `fuel_calc_forUSER_ovc.py`

- ✅ Ручной ввод параметров.
- ✅ Вывод только результата (или ошибки) – **без PASS/FAIL**.
- ✅ Копирование результата.
- ✅ Информация о самолёте.

**Используйте эту версию, чтобы:**
- Быстро рассчитать топливо для одного рейса.
- Получить понятный результат без лишней технической информации.

---

### 3. Пользовательская с пакетной загрузкой (для работы с файлами)
**Файл:** `fuel_calc_forUSER_ovc_dop.py`

- ✅ Ручной ввод параметров.
- ✅ Загрузка **TXT-файла** с набором параметров (пакетный расчёт).
- ✅ Вывод результатов для каждой строки файла.
- ✅ Кнопка **«Пример TXT»** – показывает правильный формат файла.
- ✅ Копирование результатов.

**Используйте эту версию, чтобы:**
- Рассчитать топливо для множества рейсов из одного файла.
- Автоматизировать расчёты при большом объёме данных.

## ⚙️ Установка и запуск

### Требования
- Python 3.7 или выше
- Установленные библиотеки:
  - `customtkinter`
  - `Pillow`

### Шаг 1. Клонировать репозиторий
```bash
git clone https://github.com/your_username/fuel-calculator.git
cd fuel-calculator
```

### Шаг 2. Установить зависимости
```bash
pip install customtkinter Pillow
```

### Шаг 3. Запустить нужную версию
```bash
python fuel_calc_OVC_admin.py          # админская версия
python fuel_calc_forUSER_ovc.py        # пользовательская простая
python fuel_calc_forUSER_ovc_dop.py    # пользовательская с TXT
```
